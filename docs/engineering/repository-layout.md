# Repository Layout

| | |
|---|---|
| **Status** | Accepted |
| **Last reviewed** | 2026-11-13 |

Follows the official Go guidance for server projects
([go.dev/doc/modules/layout](https://go.dev/doc/modules/layout)): commands in
`cmd/`, private code in `internal/`, and `pkg/` only for intentionally public,
SemVer-stable packages. (The popular `golang-standards/project-layout` repository
is **not** an official standard, and we don't follow it wholesale.)

```text
wickframe/
├── .github/
│   ├── workflows/            # ci.yml, nightly.yml, release.yml, codeql.yml, scorecard.yml
│   ├── ISSUE_TEMPLATE/       # bug, feature, indicator-mismatch, connector-request (YAML forms)
│   ├── PULL_REQUEST_TEMPLATE.md
│   ├── CODEOWNERS
│   └── renovate.json
├── api/
│   └── openapi.yaml          # GENERATED from code (ADR-0007); committed; CI checks freshness
├── cmd/
│   ├── wickframe/            # main server/CLI binary (cobra commands; thin)
│   └── wickframe-desktop/    # Wails v3 shell (M3)
├── internal/
│   ├── app/                  # composition root, roles, supervision tree
│   ├── config/
│   ├── platform/             # clock, id, logx, metricsx, secret, supervise, retry, httpx (SSRF-safe client)
│   ├── bus/
│   ├── marketdata/
│   │   ├── connector/        # binance/, kraken/, coinbase/, alpaca/, csv/, fake/
│   │   └── ...               # pipeline, aggregate, history, gaps, catalog
│   ├── indicator/            # engine, registry, builtin/, cache/, docs/
│   ├── workspace/
│   ├── alert/
│   ├── notify/               # channel/{webhook,smtp,telegram,discord,ntfy}, outbox
│   ├── identity/
│   ├── audit/
│   ├── api/
│   │   ├── httpapi/          # huma operations, middleware
│   │   └── ws/               # wickframe.v1 protocol gateway
│   ├── store/
│   │   ├── sqlite/           # sqlc.yaml, queries/, db/ (generated), repositories
│   │   ├── postgres/
│   │   └── storetest/        # shared contract tests
│   ├── archtest/             # import-rule tests (ADR-0003)
│   └── webui/                # embed.FS of web/dist
├── migrations/               # embed.go embeds both directories into the binary
│   ├── sqlite/               # NNNNN_name.sql (goose)
│   └── postgres/             # same numbers/names
├── pkg/
│   └── connectortest/        # public connector conformance kit
├── web/                      # frontend (see architecture/10-frontend.md)
├── deploy/
│   ├── compose/              # docker-compose.yml (+ sqlite variant)
│   ├── helm/                 # (M3)
│   └── observability/        # Grafana dashboards, Prometheus alert rules
├── testdata/
│   ├── indicators/           # reference fixtures (generated by tools/refgen)
│   └── connectors/           # recorded sessions per connector
├── tools/                    # go.mod: Go dev tools via `tool` directives, kept out of the app module
│   └── refgen/               # offline TA-Lib fixture generator (Python, not shipped)
├── docs/                     # this documentation
├── .editorconfig  .gitignore  .gitattributes
├── .golangci.yml             # golangci-lint v2 config
├── .goreleaser.yaml
├── Dockerfile                # used by GoReleaser (distroless)
├── Makefile                  # dev, check, test, build, generate, release-dry-run
├── go.mod  go.sum            # go 1.27 + toolchain; app dependencies only
├── LICENSE  README.md  CONTRIBUTING.md  SECURITY.md  CODE_OF_CONDUCT.md  THIRD_PARTY_NOTICES
└── CHANGELOG.md              # generated from Conventional Commits at release
```

## Generated code

| Generated | By | Committed? |
|---|---|---|
| `internal/store/*/db/` | sqlc | Yes. Reviewable; builds without the generator. |
| `api/openapi.yaml` | `wickframe openapi` | Yes. The API diff is reviewed in pull requests. |
| `web/src/api/generated/` | orval ([ADR-0019](../adr/0019-typescript-api-client-generator.md)) | Yes |
| `testdata/indicators/*` | `tools/refgen` | Yes |
| `web/src/app/routeTree.gen.ts` | TanStack Router Vite plugin | Yes. `tsc` needs it before the first build. |
| `web/dist/` | Vite | **No.** Built in CI and release; `internal/webui` embeds a placeholder in dev. |

`make generate` regenerates everything. CI runs it and fails on any diff.

## Make targets (contract)

| Target | Does |
|---|---|
| `make dev` | Backend with live reload + Vite dev server (proxy `/api` to Go) + fake connector |
| `make check` | Everything CI runs locally: lint, type-check, tests, generate-diff |
| `make test` / `make test-integration` / `make e2e` | Test tiers |
| `make migration name=<x>` | Creates the next numbered, empty migration in both `migrations/sqlite` and `migrations/postgres` |
| `make build` | `web` build + Go binary for the host platform |
| `make release-dry-run` | `goreleaser release --snapshot --clean` |
